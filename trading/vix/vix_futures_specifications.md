# Спецификации фьючерсов на индекс волатильности Cboe (VIX®)

Оригинальный источник: [Cboe VIX Futures Specifications](https://www.cboe.com/tradable-products/vix/vix-futures/specifications)

| Характеристика | Описание |
| :--- | :--- |
| **Название контракта** | Фьючерсы на индекс волатильности Cboe (Cboe Volatility Index - VX Futures) |
| **Тикеры** | **VX** (включает стандартные месячные и еженедельные контракты, обозначаемые цифрами недель) |
| **Базовый актив** | Ожидаемая 30-дневная волатильность индекса S&P 500 (Индекс VIX) |
| **Биржа (Торговая платформа)** | Cboe Futures Exchange (CFE) |
| **Мультипликатор контракта** | **$1,000** |
| **Минимальное изменение цены (размер тика)** | • **0.05** пункта индекса (**$50.00** на контракт) для стандартных сделок.<br>• **0.01** пункта индекса (**$10.00** на контракт) для спредов и сделок по цене расчетов (Trade At Settlement - TAS). |
| **Сроки экспирации** | • До 9 ближайших последовательных месяцев.<br>• До 5 месяцев из февральского квартального цикла.<br>• До 6 ближайших еженедельных (Weekly) экспираций. |
| **Часы торгов (по времени Чикаго, CT)** | • **Расширенные (Extended):** 17:00 (предыдущего дня) – 08:30 (с понедельника по пятницу)<br>• **Регулярные (Regular):** 08:30 – 15:00<br>• **Расширенные (Extended):** 15:00 – 16:00<br>*(Рыночные ордера (Market Orders) принимаются только в регулярные часы торгов)* |
| **Метод расчетов** | Расчет наличными (Cash-settled) на следующий рабочий день после даты экспирации. |
| **Дата окончательных расчетов** | • **Стандартные:** Среда, за 30 дней до третьей пятницы календарного месяца, следующего за месяцем экспирации.<br>• **Еженедельные:** Среда недели, указанной в тикере. |
| **Цена окончательных расчетов** | Специальная котировка открытия (Special Opening Quotation - SOQ) индекса VIX, рассчитываемая в день расчетов. |

## Дополнительные детали

* **Торговля по цене расчетов (TAS - Trade At Settlement):** Биржа CFE позволяет заключать сделки по цене расчетов для фьючерсов на VIX. Сделки TAS могут заключаться по цене окончательных расчетов текущего дня, либо на несколько тиков выше или ниже этой цены (с шагом 0.01).
* **Рыночные ордера (Market Orders):** Принимаются биржей только во время регулярных часов торгов. Любые рыночные ордера, полученные в расширенные часы, автоматически отклоняются или аннулируются.
